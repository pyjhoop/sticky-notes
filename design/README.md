## 주의 — 디자인과 v1 구현의 차이

디자인은 옵시디언 양방향 동기화를 전제로 그려졌지만 **v1은 SQLite 단독이다.**

- 동기화 관련 UI(푸터 `Vault / …`, 보드 `Vault 동기화`, 카드 `동기화됨`/`로컬 전용`/`동기화 대기`, 트레이 `지금 볼트와 동기화`, 설정 `OBSIDIAN` 섹션)는 **레이아웃을 유지하고 의미만 바꾼다**
- **충돌 상태(`볼트 버전이 더 최신`)는 구현하지 않는다**
- `fonts.googleapis.com` 링크는 옮기지 않는다 — 폰트는 로컬 번들

정확한 대응표는 `plan.md`의 "디자인 대비 변경점" 절.
